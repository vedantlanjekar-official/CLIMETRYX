# Data dictionary

| Field | Unit or domain | Missing-value rule |
| --- | --- | --- |
| Latitude / longitude | Decimal degrees, EPSG:4326 | Required before a run unless the user accepts low precision. 0, 0 is rejected. |
| Geocoder match | `place_name_candidate` or `user_confirmed_point` | A place-name match is not a rooftop. |
| Daily maximum temperature | °C | Missing days are omitted from the hot-day share. No temperature means heat is not scored. |
| Precipitation | mm per day | A 72-hour total is calculated only when all three days exist. |
| Wind gust | Stored as m/s after conversion from km/h when that is the provider unit | Unsupported units fail the adapter. |
| Rainfall percent of normal | Percent | Requires five baseline years. Otherwise drought is `not_available`. |
| NDVI | Dimensionless, (B08 − B04) / (B08 + B04) | Not calculated until bands are processed. |
| Population exposure | People per modelled flood cell | Context only. `used_in_score` stays false. |
| Cash runway | Days | Cash divided by daily fixed cost. Missing cash is null. |
| Stress revenue at risk | Currency of the profile | Hypothetical. Not a predicted loss. |
| Vulnerability score | 0–100, higher is more vulnerable | Null when no component has evidence. |
| Evidence completeness | 0–100 percent of evidence slots | Independent of the vulnerability score. |
| Tri-state answers | yes, no, unknown | Unknown is excluded, not treated as no or yes. |

Assessment status values include `queued`, `fetching_data`, `completed`, `completed_with_limitations`, `needs_configuration`, and `failed`.
